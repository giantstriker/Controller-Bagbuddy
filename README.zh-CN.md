# Controller Bagbuddy

Windows 工具：根据背包/物品栏截图划分大区与格子，激活后用热键把鼠标滑到对应格子。

本目录 **`code.py` 即为当前版本源码**，与随附 EXE 功能对齐。

## 环境要求

- Windows 10/11
- 管理员权限（UAC）：全局热键与移鼠需要
- 源码运行：Python 3.9+、[Pillow](https://pypi.org/project/Pillow/)
- 打包 EXE：[PyInstaller](https://pyinstaller.org/)

## 快速开始

1. 运行 `Controller Bagbuddy.exe`（或 `python code.py`）。
2. 通过 UAC 提权。
3. **打开截图** 或 **粘贴截图**。
4. 框选/调整大区，设置列、行。
5. **目标分辨率** 设成与游戏一致。
6. 在底栏点按键块 → 按下实键完成绑定。
7. 按 **激活** 热键，再用格子方向热键移动鼠标。

## 打包

```bat
pyinstaller --noconfirm --clean --onefile --windowed --uac-admin ^
  --name "Controller Bagbuddy" --icon backpack_tool.ico ^
  --distpath . --workpath build_tmp --specpath build_tmp code.py
```

成功后可删除 `build_tmp`。目录内只保留一个正式 EXE。

## 界面说明

### 左侧栏

- **打开 / 粘贴截图**：载入编辑用参考图。
- **全局锁定**：锁住全部大区，防止误拖。
- **屏幕辅助线**：全屏格子引导（移鼠激活时为绿色）。
- **背包界面 / 层级**
  - 单击切换当前界面。
  - 右键：重命名。
  - 右侧按键按钮：为该界面绑定专属切换热键。
  - **色**：特征点识色（自动切界面）。左键编辑，右键清空。
  - 下方：新增 / 复制 / 删除。
- **当前界面的大区**
  - 单击选中；右键：改名 / 链接 / 删除。
  - 右侧 **锁定**：单区锁定。
  - 下方：新增 / 复制 / 删除，以及名称、列、行、格子尺寸等。
- **跨区域移动**：有链接时跨区的总开关。
- **保存 / 复制 JSON / 导出**：写入或导出当前配置。
- **配置文件（多游戏）**：切换、另存等，文件在 `configs/`。

### 中间画布

- 拖拽创建或调整当前大区（未锁定时）。
- 格子点由列×行与格子尺寸决定。
- 当前区描边为绿色（`#00e676`），其它区为白色。

### 底部热键栏

两行操作。点按键块后按键绑定。常用项：

| 操作 | 作用 |
|------|------|
| 激活 | 开/关移鼠模式 |
| 辅助线 | 开/关屏幕辅助线 |
| 全局锁 | 开/关全局锁定 |
| 上个 / 下个区域 | 在当前界面的大区间切换 |
| 朝左/右/上/下一格 | 鼠标滑到相邻格子 |
| 上一 / 下一界面 | 切换布局 |

另有完整的 **快捷键设置** 窗口，可改同一套绑定。

## 功能操作

### 1. 截图与大区

1. **打开** 或 **粘贴** 图片。
2. 选中或新增大区，在画布上拖拽调整。
3. 设置 **列** / **行**。格子宽高按「区域尺寸 ÷ 列/行」自动填入。
4. 原点：**格子中心**（默认）或 **左上角**。
5. **按格子尺寸重算大区**：用当前格子宽高反推区域框。

坐标为图像像素；运行时按该界面的 `res_w` × `res_h` 映射到屏幕。

### 2. 多界面

不同 UI（背包、仓库、商店等）用不同界面：

- 每行右侧按键 = 该界面专属切换热键。
- **上一 / 下一界面** 热键在列表中循环。
- **复制** 会复制大区与特征点。

### 3. 跨区域链接

1. 大区右键 → 链接左 / 右 / 上 / 下到其它大区。
2. 打开 **跨区域移动**（建立链接时会自动打开）。
3. 走到边缘时：有链接则进入邻区；无链接则卡住（不环绕）。总开关关闭时仅在本区内环绕。

跨区轴向由区域 **中心点** 相对位置决定。

### 4. 特征点「色」（自动切界面）

1. 先载入与实机 UI 一致的截图。
2. 点目标界面右侧 **色**。
3. **开始点选** → 在画布上点稳定像素 → **保存并开启**。
4. 每点记录图像坐标 `(x,y)`、RGB、容差（默认 ±15）。
5. 运行中约每 0.4s 采样屏幕对应像素；某界面 **全部** 特征点命中则切到该界面。
6. 右键 **色**：清空并关闭该界面的识色。
7. `feature_points` 为空 = 关闭（默认）。

多界面同时命中时优先保持当前界面；另有短冷却减轻抖动。

### 5. 鼠标移动

格子间为极快的多步相对滑动（`SendInput`），最后校正落点，模拟真实滑动而非瞬移。

### 6. 配置文件

- 路径：`configs/<名>.json`。
- 左侧配置区切换；**保存** 写入当前文件。
- 内容含 `layouts`、`hotkeys`、`cross_region`。

结构示例：

```json
{
  "layouts": [
    {
      "name": "背包",
      "switch_key": "d",
      "res_w": "1920",
      "res_h": "1080",
      "feature_points": [],
      "regions": [
        {
          "name": "区域1",
          "rx1": 40, "ry1": 40, "rx2": 440, "ry2": 280,
          "cols": 10, "rows": 5,
          "cell_w": "", "cell_h": "",
          "origin": "center",
          "locked": false,
          "link_left": null, "link_right": null,
          "link_up": null, "link_down": null
        }
      ]
    }
  ],
  "hotkeys": {},
  "cross_region": false
}
```

`feature_points` 单项：`{ "x", "y", "r", "g", "b", "tol" }`（图像像素）。

## 帮助 / 排障

| 现象 | 处理 |
|------|------|
| 热键无反应 | 以管理员运行；在底栏重新绑定；确认没有停在「请按键…」捕获状态。 |
| 鼠标不动 | 先 **激活**；核对目标分辨率；确认大区列/行大于 0。 |
| 第二次载入截图仍是旧图 | 使用已修复缓存的当前 `code.py`/EXE；可重新截图后 **粘贴**。 |
| 辅助线挡操作 | 关掉辅助线；Windows 下辅助线一般为点击穿透。 |
| 无法跨区 | 大区右键建好链接，并打开 **跨区域移动**。 |
| 不会自动切界面 | 在匹配实机的截图上设特征点；加大容差；`res_w`/`res_h` 与游戏一致。 |
| 打包无法覆盖 EXE | 先退出已提权的程序再打包；若生成 `*_更新.exe`，退出后再替换。 |
| 更新后配置不见 | 查看 `configs/` 与 `active_config.json`；仅当 `configs` 为空时才会自动迁入旧根目录布局文件。 |
